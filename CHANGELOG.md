# История версий

## 1.2.2 — 19 ноября 2026

- Если на общей камере людей меньше, чем окон, человек по-прежнему идёт в окно со своей стороны кадра.
- В пустое окно ставится **свободная часть этой же камеры** (место, где сидел бы второй гость): тот же зум, что у занятого окна, кроп не выходит за край кадра, сам гость в пустом окне не виден.
- Если на общей камере никого нет, её окна делят картинку поровну слева направо, одним зумом.
- В статусе: «в окне N пустое место».

## 1.2.1 — 19 ноября 2026

- Исправлено дублирование гостя: одно лицо больше не ставится в два окна одной камеры с разным зумом.
- Человек назначается в окно по положению в кадре (слева / справа).
- Метка **«● ЭФИР»** обновляется сама, раз в две секунды, по входу в Program — не нужно обновлять список вручную.

## 1.2.0 — 18 ноября 2026

- Шаблоны в `шаблоны.txt` задаются **по названию входа vMix**, не только по номеру. Сначала ищется точное совпадение регистра («Трое» и «трое» — разные входы), затем без учёта регистра, затем номер. Если номер устарел (вход удалили, нумерация сдвинулась), программа пробует найти вход по имени слева и пишет предупреждение.
- Порядок поиска окон: картинка рамок (PNG, Image или ImageSequence) → `окна.json` (по имени .mov) → альфа-канал видео → положение слоёв камер.
- Перед отправкой в vMix окна проверяются: слишком маленькие (меньше 200 px), нечитаемые, выходящие за кадр или сильно пересекающиеся — кадрирование отменяется, в статусе будет ошибка.
- Кнопка **«Отменить»** возвращает слоям прежние zoom / pan / crop после кадрирования.

## 1.1 — 30 октября 2026

- Несколько гостей на одной камере: N окон получают N разных лиц слева направо.
- Рамки можно добавлять в vMix как Image или ImageSequence; поддерживаются вертикальные окна.

## 1.0 — 29 октября 2026

- Первый публичный релиз: автокадрирование гостей в шаблоне vMix по кнопке «Кадрировать».

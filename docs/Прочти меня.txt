MetrAutoFrame — автокадрирование гостей для vMix (МЭТР FM)
© 2026 Михаил Пирогов · PirogovLab

ЧТО ДЕЛАЕТ
По кнопке «Кадрировать» (после отсчёта 3-2-1) программа берёт свежие кадры камер,
находит лица и подгоняет zoom/pan/crop слоёв-камер выбранного шаблона vMix так,
чтобы головы были одного размера, на одной линии глаз и по центру окон.
Preview/Program, цвет и другие входы программа не трогает.

КАК ПОЛЬЗОВАТЬСЯ
1. Запустите MetrAutoFrame.exe (установка не нужна).
2. Выберите шаблон в списке «Шаблон» (● ЭФИР — шаблон, который сейчас в эфире).
3. Нажмите «Кадрировать». Ползунок «Крупность» — мельче/крупнее (сразу применяется).
   «Отменить» возвращает предыдущее кадрирование. Красная полоса в превью =
   с этой стороны камере не хватает картинки.


ЧТО НОВОГО В 1.2.2
Если на камере несколько окон, а людей меньше (например «Трое»: окна 2 и 3 —
камера 7), человек ставится в окно со своей стороны кадра. В пустое окно
показывается свободная часть этой же камеры — то место, где сидел бы второй
гость, с тем же зумом, без этого человека в кадре. Если на камере никого нет,
окна делят картинку поровну слева направо. В статусе: «в окне N пустое место».
Лишние лица (больше, чем окон) не используются. Метка «● ЭФИР» обновляется
сама, раз в две секунды, по тому входу, который сейчас в Program.

ФАЙЛ «шаблоны.txt» (рядом с exe)
  Отображаемое имя = название входа vMix   (предпочтительно)
  или: Отображаемое имя = номер входа      (если название неизвестно)
  Примеры:
    Двое в студии = Двое
    Выездной эфир = 10
  Поиск — по названию без учёта регистра, если не найдено — по номеру.
  Если номер больше не тот (вход удалили, нумерация сдвинулась), программа
  попробует найти вход по имени слева и напишет предупреждение.
  vMix = 192.168.0.100          (адрес vMix, необязательно)
  # комментарий
Список в программе показывает только эти строки, в том же порядке.
Файл перечитывается автоматически. Если файла нет — программа создаст его сама
(уже с названиями входов). Настройки сохраняются в MetrAutoFrame.json рядом с exe.

ОТМЕНА
Если шаблон в эфире, отсчёт 3-2-1 перед кадрированием остаётся.
После кадрирования кнопка «Отменить» возвращает слоям прежние zoom/pan/crop.

ОКНА
Порядок поиска окон: картинка рамок (PNG) → окна.json (по имени .mov) →
альфа-канал видео → положение слоёв камер. Источник окон пишется в статусе.
Если окна меньше 200 px, не читаются, выходят за кадр или сильно пересекаются,
кадрирование не отправляется в vMix — в статусе будет ошибка.

ТРЕБОВАНИЯ
- Windows 10/11.
- vMix с включённым Web Controller (Settings → Web Controller, порт 8088).
- Для удалённого vMix: DP Thumbnail Server (adelvo.io, порт 8098) на машине vMix —
  через него берутся кадры камер. На локальном vMix он не обязателен.
- В шаблоне: слои-камеры и (желательно) картинка рамок с прозрачными окнами
  (имя входа содержит «шаблон», «рамк», «frame» или «okna»).

- Окна можно задать и прозрачными «дырками» в альфа-канале видео-оформления (.mov) в слое шаблона.
  Найденные окна хранятся в «окна.json» рядом с exe (ключ — имя видео), поэтому на другом
  компьютере ни .mov, ни ffmpeg не нужны. Для нового видео-оформления: один раз запустить программу там,
  где есть ffmpeg и сам .mov (C:\МЭТР FM\vMix или рядом с exe) — окна допишутся в окна.json сами.
